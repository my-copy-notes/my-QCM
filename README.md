# My QCM

**よく使う文章を整理して、必要な文章をすぐコピーするための自分専用Webアプリ**です。

## Ver.1 の機能

- メモの作成・編集・削除
- 一覧からワンタップで本文をコピー
- お気に入り
- カテゴリ（タブ）分け
- フォルダ／サブフォルダによる階層整理
- 検索
- IndexedDBによる端末内保存
- JSONバックアップの書き出し・復元
- ホーム画面追加対応
- 一度読み込んだ後のオフライン利用に備えたService Worker

## 大切なこと

入力したメモ本文はGitHubには保存されません。実際のメモデータは、使用しているブラウザのIndexedDBに保存されます。

ただし、SafariのWebサイトデータ削除や端末変更に備えて、定期的にアプリ内の「バックアップ」を書き出してください。

## GitHub Pagesで使う

リポジトリの **Settings → Pages** から、`main` ブランチのルートを公開するとブラウザで利用できます。

公開後、iPhoneのSafariで開いて **共有 → ホーム画面に追加** を選ぶと、アプリのように起動できます。
